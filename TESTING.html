Sistema de Mensagens entre Utilizadores - Módulo 6

📋Pré-Requisitos

Antes de começar os testes, certifique-se que tem tudo instalado:

  • PHP 7.4 ou superior
  • Extensão SQLite3 ativada
  • Terminal/CMD (PowerShell, Bash, etc.)
  • Navegador web moderno
  • Projeto descarregado

Verificar PHP

php --version

Verificar SQLite

php -m | grep sqlite
✅ Se ambos os comandos funcionarem, está pronto para começar!

🎯Cenários de Teste Completos

Cenário 1: Chat Web Básico

Objetivo: Verificar se duas pessoas conseguem trocar mensagens em tempo real
  1. Abra 2 abas do navegador
  2. Primeira aba: Login com alice
  3. Segunda aba: Login com bob
  4. Na aba da alice: clique em bob
  5. Envie mensagem: \"Olá Bob\"
  6. Vire para aba do bob e aguarde ~3 segundos
✅ Esperado: Mensagem aparece em tempo real

Cenário 2: Integração CLI + Web

Objetivo: Verificar se CLI e Web podem comunicar
  1. CLI: Envie mensagem para alice
  2. Web (alice): Veja a mensagem aparecer
  3. Web (alice): Responda a pedro (usuario CLI)
  4. CLI: Escolha opção 2 para ver conversas
✅ Esperado: Mensagens sincronizadas entre plataformas

Cenário 3: Histórico de Conversas

Objetivo: Verificar se histórico é mantido após refresh
  1. Envie 5 mensagens entre 2 utilizadores
  2. Faça F5 (refresh) na página
  3. Verifique se todas as mensagens continuam lá
  4. Feche a aba e abra novamente o navegador
  5. Faça login novamente
✅ Esperado: Histórico completo ainda visível

Cenário 4: Lista de Contactos

Objetivo: Verificar se lista atualiza com novos utilizadores
  1. Crie 3 utilizadores diferentes
  2. Verifique se todos aparecem na lista
  3. Verifique se mostra \"Último acesso\"
  4. Aguarde 1 minuto sem atividade
  5. Faça refresh e veja tempo atualizado
✅ Esperado: Lista com todos os utilizadores e tempos corretos

Cenário 5: Responsividade Mobile

Objetivo: Verificar se interface funciona em dispositivos móveis
  1. Abra o navegador (F12 ou Dev Tools)
  2. Clique em \"Toggle Device Toolbar\" (ou Ctrl+Shift+M)
  3. Selecione um dispositivo móvel (iPhone, etc.)
  4. Teste envio/receção de mensagens
  5. Verifique se layout adapta-se bem
✅ Esperado: Interface adaptada, sem overflow horizontal

🔧Resolução de Problemas

❌ Erro: \"Address already in use\"

Causa: Outra aplicação já está usando a porta 5555

Solução:

# Opção 1: Mude a porta no arquivo server/config.php
define('SERVER_PORT', 5556); # Mude para outra porta

❌ Erro: \"Call to undefined function sqlite_*\"

Causa: SQLite3 não está ativado no PHP

Solução:

# Ative SQLite3 em php.ini
# Descomente a linha:
extension=sqlite3

❌ Erro: \"Permission denied\"

Causa: Sem permissão para criar arquivos

Solução (Linux/Mac):

chmod -R 755 database/

❌ Mensagens não aparecem

Causa: Servidor pode não estar rodando

Checklist:

  • ✓ Servidor está rodando no Terminal 1?
  • ✓ Fez F5 para atualizar a página?
  • ✓ Nomes dos utilizadores são diferentes?
  • ✓ Verifique os logs do servidor

❌ Erro: \"connection refused\"

Causa: Servidor TCP não está acessível

Solução:

# Verifique se servidor está rodando
netstat -an | grep 5555 # Linux/Mac
netstat -an | findstr 5555 # Windows

💡Dicas Úteis

💾 Como Limpar a Base de Dados

Se quiser começar do zero:

rm database/messages.db
# Na próxima execução, será criada uma nova BD

🔍 Ver Base de Dados Diretamente

Se tem SQLite instalado:

sqlite3 database/messages.db
.tables # Ver tabelas
SELECT * FROM messages; # Ver mensagens
SELECT * FROM users; # Ver utilizadores

📱 Testar em Outro Computador

Para testar em rede local:

  1. Descubra seu IP: ipconfig (Windows) ou ifconfig (Linux)
  2. Mude em client/web/index.php: SERVER_HOST para seu IP
  3. No outro computador: http://[seu-ip]:8000

🐛 Modo Debug

Para mais informação sobre erros:

# Adicione ao início de server.php:
error_reporting(E_ALL);
ini_set('display_errors', 1);
